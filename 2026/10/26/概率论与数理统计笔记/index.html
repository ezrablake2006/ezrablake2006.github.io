概率论与数理统计笔记

§3 连续型随机变量

3.1 随机变量的分布函数

定义：$F(x) = P(X \le x)$，表示随机变量 $X$ 落在 $(-\infty, x]$ 内的概率。

核心性质：

  1. 有界性：$0 \le F(x) \le 1$，且 $F(-\infty) = \lim_{x \to -\infty} F(x) = 0$，$F(+\infty) = \lim_{x \to +\infty} F(x) = 1$。
  2. 区间概率计算：$P(a < X \le b) = F(b) - F(a)$。

3.2 连续型随机变量及其密度函数

定义关系：

$$F(x) = \int_{-\infty}^{x} f(t) , dt$$

其中 $f(x)$ 称为概率密度函数。在 $f(x)$ 的连续点处，有 $F’(x) = f(x)$。

归一性：$\int_{-\infty}^{+\infty} f(x) , dx = 1$（曲线下总面积为 1）

3.3 连续型随机变量的数学期望与方差

$$E(X) = \int_{-\infty}^{+\infty} x f(x) , dx$$

$$E[g(X)] = \int_{-\infty}^{+\infty} g(x) f(x) , dx$$

$$D(X) = \text{Var}(X) = E[(X - E(X))^2] = \int_{-\infty}^{+\infty} [x - E(X)]^2 f(x) , dx$$

$D(X) = E(X^2) - [E(X)]^2$，其中 $E(X^2) = \int_{-\infty}^{+\infty} x^2 f(x) , dx$。

$E(aX + b) = aE(X) + b$

$D(aX + b) = a^2 D(X)$

3.4 常用连续型随机变量及分布

3.4.1 均匀分布

均匀分布：落在 $(a,b)$ 内任一子区间的概率仅与区间长度成正比。

$$X \sim U(a, b)$$

$$E(x)=\frac{a+b}{2}$$

$$Var(x)=\frac{(b-a)^2}{12}$$

3.4.2 正态分布

正态分布：钟形对称曲线，对称轴为 $x=\mu$；$\mu$ 决定位置（期望），$\sigma$ 决定胖瘦（标准差）。

$$X \sim N(\mu, \sigma^2)$$

密度函数：$f(x)=\frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$（记忆！）

正态分布的分布函数没有初等表示，必须通过查表解决。

在 $x = \mu$ 处取得最大值 **$f(\mu) = \frac{1}{\sqrt{2\pi}\sigma}$**；在 $x = \mu \pm \sigma$ 处有两个拐点。

标准正态分布：当 $\mu = 0, \sigma = 1$ 时，称 $Z \sim N(0, 1)$ 为标准正态分布。

概率密度函数：$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$（偶函数：$\varphi(-x) = \varphi(x)$）

三大铁律：

  • 中点值：$\Phi(0) = 0.5$

  • 正负转换公式：**$\Phi(-x) = 1 - \Phi(x)$**

  • 对称区间公式：$P(\vert{}Z\vert{} \le a) = P(-a \le Z \le a) = \Phi(a) - \Phi(-a) = 2\Phi(a) - 1$

一般正态分布的“标准化”：若 $X \sim N(\mu, \sigma^2)$，则令 **$Z = \frac{X - \mu}{\sigma}$**，必有 **$Z \sim N(0, 1)$**。

计算公式：

  1. $P(X \le a) = P\left(\frac{X-\mu}{\sigma} \le \frac{a-\mu}{\sigma}\right) = \Phi\left(\frac{a-\mu}{\sigma}\right)$
  2. $P(a < X \le b) = \Phi\left(\frac{b-\mu}{\sigma}\right) - \Phi\left(\frac{a-\mu}{\sigma}\right)$

3.4.3 指数分布

$$X \sim E(\lambda), f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \ 0, & x \le 0 \end{cases}$$

$$F(x) = \begin{cases} 1 - e^{-\lambda x}, & x > 0 \ 0, & x \le 0 \end{cases}$$

$$P(X > a) = 1 - F(a) = \mathbf{e^{-\lambda a}}$$

$$P(a < X \le b) = F(b) - F(a) = (1 - e^{-\lambda b}) - (1 - e^{-\lambda a}) = \mathbf{e^{-\lambda a} - e^{-\lambda b}}$$

$$E(x)=\frac{1}{\lambda}$$

$$D(x)=\frac{1}{\lambda^2}$$

性质：无记忆性，对于任意 $s > 0, t > 0$，恒有：

$$P(X > s + t \mid X > s) = P(X > t)$$

3.5 连续型随机变量函数的分布

已知 $X$ 的密度函数 $f_X(x)$，求 $Y = g(X)$ 的密度函数 $f_Y(y)$：

分布函数法（通法）：

  • 第一步：先写 $Y$ 的分布函数 $F_Y(y) = P(Y \le y) = P(g(X) \le y)$。
  • 第二步：解不等式，将其转化为关于 $X$ 的概率（如 $P(X \le h(y))$），用 $F_X$ 表示。
  • 第三步：对 $y$ 求导，得到 $f_Y(y) = F’_Y(y)$，并注明 $y$ 的取值范围。
