所有需要执行的代码都必须位于被声明为 public static void main(String[] args) 的方法内部。

在 Java 中，将一个程序文件转换为可执行文件的过程主要包括两个步骤：编译和解释。要运行 Hello.java 中的代码，我们首先需要使用 javac HelloWorld.java 命令将代码编译为 .class 文件。然后，要运行代码，我们就会使用 java HelloWorld 命令。

Java程序的几个规则：

  1. 所有变量必须在使用之前被声明出来，并且还需要指定其类型。在整个程序中，类型不可改变。Java 是一种静态类型语言，这意味着所有的变量、参数和方法都必须声明其类型。一旦声明后，类型就不能再更改。表达式也具有隐式类型；例如，表达式 3 + 5 的类型就是 int 。
  2. 因为所有类型都是静态声明的，所以在程序运行之前，编译器就会检查这些类型是否兼容。这意味着，如果表达式中的类型不兼容，那么表达式将无法编译，而不会导致程序在运行时崩溃。
  3. 由于所有的 Java 代码都属于某个类，因此我们必须定义那些属于某个类的函数。属于某个类的函数通常被称为“方法 methods”。我们使用 public static 这个关键字来声明方法。

1.3 引用、递归和列表

平等黄金法则（GRoE）：当你写 x = y 时y = x，你是在告诉 Java 解释器将 x 中的位复制到 y 中。当你向函数传递参数时，实际上就是在复制数据位。换句话说，GRoE 也适用于参数传递。复制数据位通常被称为“按值传递”。在 Java 中，我们总是按值传递数据。
